# 🥗 ProDiet-AI: Akıllı Haftalık Diyet Planlayıcı

ProDiet-AI, kullanıcıların fiziksel verilerini analiz ederek onlara özel, sürdürülebilir ve dengeli **haftalık diyet programları** hazırlayan modern bir web uygulamasıdır. Veriye dayalı yaklaşımıyla sağlıklı yaşam yolculuğunuzda size rehberlik eder.

## 🚀 Canlı Uygulama
Uygulamayı hemen test etmek için aşağıdaki bağlantıya tıklayabilirsiniz:
👉 **[ProDiet-AI Uygulamasını Aç](https://appiet-ai-9yvcnkspla9wdgys5l4pvm.streamlit.app/)**

## ✨ Öne Çıkan Özellikler
* **Kişiselleştirilmiş Veri Girişi:** Ad, yaş, boy, kilo, cinsiyet ve aktivite seviyesi gibi parametrelerle tam uyumlu analiz.
* **Haftalık Program Oluşturma:** Pazartesi'den Pazar'a, tüm ana ve ara öğünleri içeren detaylı diyet listeleri.
* **Akıllı Filtreleme:** Beslenme tercihlerine (Hepçil, Vejetaryen vb.) ve alerji durumlarına (Laktoz, Gluten vb.) göre dinamik menü yönetimi.
* **Makro Besin Analizi:** Hedeflenen kaloriye göre Protein, Karbonhidrat ve Yağ dağılımlarının otomatik hesaplanması.
* **Modern Dashboard:** Kullanıcı dostu, hızlı ve estetik bir arayüz deneyimi.

## 🛠️ Teknik Altyapı
* **Frontend/Backend:** [Streamlit](https://streamlit.io/) (Python)
* **Veritabanı Yönetimi:** Supabase & JSON tabanlı veri entegrasyonu.
* **Veri İşleme:** Pandas ve NumPy kütüphaneleri ile hassas hesaplamalar.
